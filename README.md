# 面積図でわかる 二桁×二桁

二桁×二桁の掛け算を面積図で4つの部分に分解して理解するインタラクティブツール

🔗 **公開URL**: https://area.meetupsensei.com/

## 概要

たての数とよこの数（10〜99）をスライダーで選ぶと、その積が長方形の面積として描かれます。それぞれの数を「十の位＋一の位」に分けることで長方形が4つの部分に分かれ、ステップごとに1つずつ色づけしながら面積を足し上げていけます。式・色分け表・合計が図と連動して更新されるので、筆算の仕組みが視覚的につかめます。日本語／英語の切り替えとダークモードにも対応しています。

## 使い方

- 「たての数」「よこの数」をスライダーまたは数値入力で 10〜99 の範囲で設定する
- 「つぎへ ▶」を押すと、4つの部分が1つずつ色づけされて面積が加算される
- 「◀ もどす」で1ステップ戻る、「全部表示」で一気に4つすべてを表示する
- 「格子線」ボタンで方眼の表示を切り替える（数が大きいときは10ごとに表示）
- 右上の「EN／日本語」で言語、「🌙／☀️」でダークモードを切り替える
